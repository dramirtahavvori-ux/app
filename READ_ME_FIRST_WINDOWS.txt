How to open this demo on Windows
================================

1. Right-click the ZIP file and choose "Extract All..."
2. Open the extracted folder.
3. Right-click OPEN_ME_IN_CHROME.html.
4. Choose "Open with" > "Google Chrome" or "Microsoft Edge".

Do not open the HTML file directly from inside the ZIP preview.
Extract the ZIP first.

If Windows blocks the file
--------------------------
1. Right-click OPEN_ME_IN_CHROME.html.
2. Choose Properties.
3. If you see "Unblock" at the bottom, check it.
4. Click Apply, then OK.
5. Open the file again with Chrome.
